# 📚 Kitobhoi Boqizoda – Online Islamic Bookstore

**Kitobhoi Boqizoda** is a modern, responsive front-end project for an Islamic digital library. It provides a beautiful and accessible way to explore, search, and read Islamic books online.

---

## ✨ Features

- 📖 Browse a curated collection of Islamic books
- 🔍 Search and filter by categories
- 🕌 Elegant design with Tailwind CSS
- 🔐 Login, Register, and Forgot Password pages
- 📱 Fully responsive for desktop and mobile
- 🌙 Background imagery for spiritual aesthetics

---

## 🛠️ Built With

- **HTML5 & CSS3**
- **Tailwind CSS**
- **JavaScript**
- **Lucide Icons**
- **Swiper.js**
- **Google Fonts** (Space Grotesk, Noto Sans)
